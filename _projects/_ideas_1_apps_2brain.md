# Aplicaciones de Windows para 2brain con Obsidian

## Apps de Windows para second brain / PKM

* [ ] **Notelyn** — captura audio de clases y reuniones, genera transcripción + resumen + puntos clave automáticamente. También procesa PDFs, YouTube y podcasts. Complemento directo al sistema supernova + NotebookLM.
* [ ] **Anki** — flashcards con spaced repetition científico. Alta retención en exámenes con carga de memorización. Hay plugin de Obsidian que exporta notas a Anki directamente.
* [ ] **Heptabase** — canvas visual infinito con notas atómicas. PDF annotation integrado y búsqueda rápida. Alternativa visual a Excalidraw para mapas conceptuales fuera de Obsidian.
* [ ] **Logseq** — sistema de flashcards nativo + anotación de PDFs con links a coordenadas específicas del documento. Basado en archivos locales, puede coexistir sobre el vault con cuidado.
* [ ] **Raindrop.io** — gestor de bookmarks. Reemplaza a Pocket/Omnivore (Omnivore cerró 2025). Para guardar links que luego se convierten en asteroid en el vault.

## Plugins de Obsidian

* [ ] **Bases** — core plugin nativo (sin instalar nada). Convierte notas en base de datos filtrable, ordenable, editable en línea. Aprovecha directamente el YAML existente del vault (galaxy_body, status, fase, etc.). Reemplaza el 80% de los casos de uso de Dataview con menos fricción.
* [ ] **Smart Connections** — conecta notas por significado semántico, no solo por links explícitos. Complementa Basic Memory cuando el vault crezca.
* [ ] **QuickAdd** — captura rápida de ideas sin interrumpir el flujo de estudio.
* [ ] **Tasks** — gestión de tareas con fechas y recurrencias dentro del vault. Se integra con el _ToDo-system.
* [ ] **Kanban** — tablero visual de tareas por materia. Trabaja junto a _projects/.
* [ ] **Spaced Repetition** — flashcards dentro del vault sin salir a Anki. Opción más liviana si no se quiere app externa.
