Considere un sistema de tiempo discreto recursivo con entrada $x(n)$ y salida $y(n)$, el cual está descrito por la siguiente ecuación de diferencias:

$$
y(n)=2y(n-1)+x(n)
$$

Si la entrada es:

$$
x(n)=\delta(n)
$$

$$
y(-1)=0
$$

## 3. Respuesta de un sistema de tiempo discreto recursivo

**Datos:**
* **Ecuación en diferencias:** $y[n] = 2y[n-1] + x[n]$
* **Entrada:** $x[n] = \delta[n]$ (impulso unitario)
* **Condición inicial:** $y[-1] = 0$
* **Rango de evaluación:** $0 \le n \le 5$

---

### Resolución analítica

Para determinar la respuesta del sistema muestra a muestra, evaluamos la ecuación en diferencias de forma recursiva hacia adelante en el tiempo:

* **Para $n = 0$:**
  
$$
y[0] = 2y[-1] + x[0] = 2(0) + \delta[0] = 0 + 1 = 1
$$

* **Para $n = 1$:**
  
$$
y[1] = 2y[0] + x[1] = 2(1) + \delta[1] = 2 + 0 = 2
$$

* **Para $n = 2$:**
  
$$
y[2] = 2y[1] + x[2] = 2(2) + \delta[2] = 4 + 0 = 4
$$

* **Para $n = 3$:**
  
$$
y[3] = 2y[2] + x[3] = 2(4) + \delta[3] = 8 + 0 = 8
$$

* **Para $n = 4$:**
  
$$
y[4] = 2y[3] + x[4] = 2(8) + \delta[4] = 16 + 0 = 16
$$

* **Para $n = 5$:**
  
$$
y[5] = 2y[4] + x[5] = 2(16) + \delta[5] = 32 + 0 = 32
$$

```ad-attention
collapse: open
Los índices estaban incompletos en la resolución original. La forma correcta es $y[n] = 2y[n-1] + x[n]$ evaluada en cada instante con sus índices explícitos. Por ejemplo para $n=1$: $y[1] = 2y[0] + x[1] = 2(1) + \delta[1] = 2 + 0 = 2$.
```


Por inducción, la respuesta impulsional (o solución general causal) para $n \ge 0$ se expresa como:

$$
y[n] = 2^n u[n]
$$


#### Análisis de Estabilidad (Polo del Sistema)
La estabilidad de un sistema lineal e invariante en el tiempo $LTI$ se determina a través de la ubicación de los polos de su función de transferencia en el plano $z$. Tomando la transformada $z$ unilateral en ambos lados de la ecuación homogénea:

$$
Y(z) - 2z^{-1}Y(z) = 0 \implies Y(z)(1 - 2z^{-1}) = 0
$$


La ecuación característica del sistema es:

$$
z - 2 = 0
$$


Esto revela que el sistema tiene un único polo simple localizado en:

$$
z = 2
$$


Dado que el polo se ubica fuera del círculo unitario en el plano $z$ ($|z| = 2 > 1$), la respuesta natural del sistema crece de forma exponencial e ilimitada cuando $n \to \infty$. Por consiguiente, el sistema es **dinámicamente inestable** bajo el criterio de estabilidad BIBO (Bounded-Input Bounded-Output).

### Código MATLAB

He generado e importado el script ejecutable `sistema_recursivo.m` en tu panel de Studio. A continuación se presenta el código completo estructurado por bloques lógicos:

```matlab
% ETN1015 — Discrete Signals and Systems
% Ejercicio: Respuesta de un sistema de tiempo discreto recursivo inestable
% Fuente: S. Palani — Cap. 1, Ej. 1.11 / Ingle & Proakis — Cap. 2, Ej. 2.15
clear; clc; close all;

% [bloque 1 — Definición de parámetros y preasignación de vectores]
N = 6;                % Número de muestras a evaluar (n = 0 a 5)
y = zeros(1, N);      % Vector de salida y[n]
x = zeros(1, N);      % Vector de entrada x[n] (impulso unitario)
x(1) = 1;             % x[0] = delta[0] = 1 — ver corrección en admonition

% Condición inicial dada: y[-1] = 0
y_prev = 0;           % Representa la muestra previa y[-1]

% [bloque 2 — Simulación paso a paso con bucle for respetando condiciones iniciales]
for n = 1:N
    if n == 1
        y(n) = 2 * y_prev + x(n);  % Para n = 0 (primer índice), depende de y[-1]
    else
        y(n) = 2 * y(n-1) + x(n);  % Para n > 0, depende del valor anterior calculado
    end
end

% [bloque 3 — Visualización de la respuesta del sistema]
n_vec = 0:5;          % Soporte temporal para la gráfica (0 <= n <= 5)
figure(1);
stem(n_vec, y, 'filled', 'LineWidth', 1.5, 'Color', [0.8500 0.3250 0.0980]);
xlabel('Índice de tiempo n');
ylabel('Amplitud y[n]');
title('Respuesta al impulso y[n] = 2y[n-1] + x[n]');
xlim([-1, 6]);
ylim([0, max(y)+5]);
grid on;
```

```ad-attention
collapse: open
El comentario original `x = delta = 1` no indicaba el índice explícito. Lo correcto es `x[0] = delta[0] = 1`, ya que el impulso unitario vale 1 solo en $n=0$ y cero para todo otro $n$. El código en sí (`x(1) = 1`) es correcto en MATLAB ya que el índice 1 corresponde a $n=0$.
```
