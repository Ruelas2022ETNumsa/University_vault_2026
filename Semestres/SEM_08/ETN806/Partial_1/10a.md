Para resolver el ejercicio 10 de la **practica.pdf**, calcularemos el **valor esperado condicional** de $X$ dado $Y$ para cada valor posible del rango de $Y$ ($y=0, 1, 2$). Para ello, seguiremos el procedimiento de tres pasos descrito en el formulario de tus fuentes.

### 1\. Calcular las probabilidades marginales $P\_Y(y)$

La probabilidad marginal de $Y$ se obtiene sumando las probabilidades conjuntas de la columna correspondiente para cada valor de $y$ 1\.

* **Para $y=0$**: $P\_Y(0) \= 0.01 \+ 0.09 \+ 0 \= \\mathbf{0.10}$  
* **Para $y=1$**: $P\_Y(1) \= 0 \+ 0.09 \+ 0 \= \\mathbf{0.09}$  
* **Para $y=2$**: $P\_Y(2) \= 0 \+ 0 \+ 0.81 \= \\mathbf{0.81}$

*Validación: $0.10 \+ 0.09 \+ 0.81 \= 1.00$ (Correcto).*

### 2\. Determinar las distribuciones condicionales $P\_{X/Y}(x/y)$

Utilizamos la fórmula: $P\_{X/Y}(x/y) \= \\frac{P\_{X,Y}(x,y)}{P\_Y(y)}$ 1\.

* **Si $y=0$**:  
* $P\_{X/Y}(0/0) \= 0.01 / 0.10 \= 0.1$  
* $P\_{X/Y}(1/0) \= 0.09 / 0.10 \= 0.9$  
* $P\_{X/Y}(2/0) \= 0 / 0.10 \= 0$  
* **Si $y=1$**:  
* $P\_{X/Y}(1/1) \= 0.09 / 0.09 \= 1$ (los demás valores de $x$ son 0).  
* **Si $y=2$**:  
* $P\_{X/Y}(2/2) \= 0.81 / 0.81 \= 1$ (los demás valores de $x$ son 0).

### 3\. Calcular los valores esperados condicionales $EX/Y=y$

Aplicamos la fórmula de la esperanza para variables discretas condicionadas: $EX/Y=y \= \\sum\_{x \\in S\_x} x \\cdot P\_{X/Y}(x/y)$ 2\.  
**a) Para $Y \= 0$:**$$EX/Y=0 \= (0 \\cdot 0.1) \+ (1 \\cdot 0.9) \+ (2 \\cdot 0)$$**$$EX/Y=0 \= 0.9$$**  
**b) Para $Y \= 1$:**$$EX/Y=1 \= (0 \\cdot 0\) \+ (1 \\cdot 1\) \+ (2 \\cdot 0)$$**$$EX/Y=1 \= 1.0$$**  
**c) Para $Y \= 2$:**$$EX/Y=2 \= (0 \\cdot 0\) \+ (1 \\cdot 0\) \+ (2 \\cdot 1)$$**$$EX/Y=2 \= 2.0$$**

### Resultados Finales:

* **$EX/Y=0 \= 0.9$**  
* **$EX/Y=1 \= 1.0$**  
* **$EX/Y=2 \= 2.0$**

**Nota conceptual:** Observa que cuando $Y=1$ o $Y=2$, la variable $X$ se vuelve "determinista" (tiene probabilidad 1 de tomar un solo valor), por lo que el valor esperado coincide exactamente con el único valor posible de $X$ en esa columna.
