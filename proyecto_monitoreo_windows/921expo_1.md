*"Mi parte cubre cómo el usuario accede al sistema desde el navegador. La carpeta `web\` tiene tres bloques:"*

- **Componente 3 (POST)** — reportes gráficos históricos consultando la base de datos.

## BLOQUE 1 — Núcleo común

### enlaces.php
Lee `enlaces.txt` y devuelve la lista de dominios como array. Todos los demás archivos la usan vía `require_once`, nadie lee el archivo directamente.

```php
$lineas = file($archivo, FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES);
// ignora comentarios (#) y sanitiza: solo letras, números, puntos y guiones
$linea = preg_replace('/[^a-zA-Z0-9.\-]/', '', $linea);
```

### ping_helper.php + ping_web.bat
La consigna exigía la cadena `Navegador → PHP → .bat → ping`. PHP no llama al ping directamente, llama al `.bat` con `shell_exec()`.

```php
$cmd = '"' . $bat . '" ' . escapeshellarg($destino_limpio) . ' 2>&1';
$salida = shell_exec($cmd);
```

El parseo acepta la salida en español (`tiempo=15ms`) e inglés (`time=15ms`) con una sola expresión regular, y toma el máximo de todos los tiempos.

## BLOQUE 2 — Componente GET

### index.php
Página principal. Genera los botones de ping dinámicamente desde la lista:

```php
foreach ($enlaces as $i => $e) {
    echo "<a href='ping_online.php?Equipo=" . ($i+1) . "' class='btn-enlace'>$e</a>";
}
```
Si el archivo tiene 10 dominios, aparecen 10 botones. Sin tocar el HTML.

### ping_online.php
Recibe `?Equipo=N` por GET, valida que el índice exista y ejecuta el ping:

```php
$equipo = isset($_GET['Equipo']) ? (int)$_GET['Equipo'] : 0;
if (!array_key_exists($equipo, $enlaces)) {
    header("Location: index.php"); exit;
}
$ping = hacer_ping($enlaces[$equipo]);
```

### estado_enlaces.php
Tabla incluida en `index.php` que muestra el último RTT de cada enlace consultando la BD, y lo clasifica con colores: OK / Lento / Muy lento / Sin respuesta.

### gestionar_enlaces.php
Agregar o quitar dominios desde el navegador sin tocar archivos a mano. El cambio se refleja en la próxima ejecución del Task Scheduler.

## BLOQUE 3 — Componente POST

### reporte.php
Recibe enlace, fecha y rango horario. MySQL calcula todo:

```sql
SELECT ROUND(AVG(rtt_max),3), ROUND(MAX(rtt_max),3), ROUND(MIN(rtt_max),3),
       ROUND(STDDEV(rtt_max),3),
       SUM(IF(rtt_max >= 0, 1, 0)) AS exitosos,
       CASE WHEN AVG(rtt_max) < 50 THEN 'Excelente' ... END AS calidad
FROM muestras WHERE enlace=? AND fecha=? AND hora BETWEEN ? AND ?
```

PHP inyecta los resultados en Chart.js como JSON para dibujar el gráfico de línea.

**Fix PHP 7.1:** `match()` (PHP 8.0+) reemplazado por `switch`.

### comparar.php
Compara todos los enlaces en un rango usando `GROUP BY`:

```sql
SELECT enlace, ROUND(AVG(rtt_max),2) AS promedio, ...
FROM muestras WHERE fecha=? AND hora BETWEEN ? AND ?
GROUP BY enlace HAVING COUNT(*) > 0 ORDER BY promedio ASC
```

Produce un diagrama de quesos y un ranking ordenado de menor a mayor RTT promedio.

**Fix PHP 7.1:** arrow functions `fn()` (PHP 7.4+) reemplazadas por funciones anónimas completas.
