# Tema VII: Método de análisis de circuitos mallas y nodos.

---

## Teoria
### Introduccion.
Para poder resolver los circuitos, se empleran los metodos de mallas y nodos.
### Analisis de circuitos por corrientes de mallas (L.T.K).
Para aplicacion de este tipo de análisis se emplearan los siguientes pasos:
1. Dar un sentido general a las corrientes generadas por las fuentes de tensión.
2. Deba haber 'n' corrientes por 'n' mallas y 'n' ecuaciones.
3. Polarizar cada componente.
4. La sumatoria de las fuentes de tensión es igual a al sumatoria de las cídas de tensión.




### Analisis de circuitos por tensiones de nodos (L.C.K).
Para el método se siguen los siguientes pasos:
1. Dada la red se debe identificar y enumerar la cantidad de nodos.
2. Al nodo mas congestionado se lo conciderara cono nodo de referencia ($V_T=0$).
3. Definir las trensions de nodo respecto al nodo enumerado.
4. Plantear la ley de corrientes de Kirchoff en cada nodo indepeniente, obteniendose tantas ecuaciones como nodos independientes se tengan.
5. Resolver el sistema de ecuaciones, con la cual el sistema esta resuelto y volvemos a la red para hallar la incognita deseada.


### Caso de super mallas y super nodos
Se usa los métodos ya vistos para la resolucion del circuito, ademas se añadira un paso extra a cada método :
- Super mallas.- Se debe anular a las fuentes de corriente (Circuito abierto) .
- Super nodos.- Se debe anular a las fuentes de tesión (Circuito acerrado).
