# Parámetros básicos

---

De toda función periódica se pueden hallar los siguientes elementos:

| Parámetro                                | formulas                                                                |
| ---------------------------------------- |:----------------------------------------------------------------------- |
| Voltage máximo                           | $V_{\mbox{max}}=\mbox{Amplitud}$                                        |
| Voltage pico a pico                      | $V_{pp}=2·V_{\mbox{max}}$                                               |
| Valor medio ( $V_M$ )                    | $V_{m}=\dfrac{1}{T}· \int_{t_0}^{t_0+T} \;f_{(t)}\; dt$                 |
| Valor eficaz ( $V_{rms},V_\varepsilon$ ) | $V_{\mbox{ef}}=\sqrt{\dfrac{1}{T}·\int_{t_0}^{t_0+T}\;(f_{(t)})^2\;dt}$ |
| Factor de forma                          | $f.f.=\dfrac{V_{\epsilon}}{V_{M}}$                                      |

## Tomar en cuenta

```ad-Nota_2
title: Para los cálculos
1. Si la función es <mark class="hltr-nota_1">simétrica desfasada respecto al origen</mark> de coordenadas.
	>$$V_M=0$$
2. Para toda función del tipo <mark class="hltr-nota_1">senoidal o cosenoidal</mark> .
	>$$V_{\epsilon}=\dfrac{A}{\sqrt{2}}$$
3. Si <mark class="hltr-nota_1">$V_M=0$</mark> y se quiere hallar el factor de forma será necesario calcular nuevamente utilizando <mark class="hltr-nota_1">medio período.</mark> 
	>$$T\rightarrow\dfrac{T}{2}$$
```
