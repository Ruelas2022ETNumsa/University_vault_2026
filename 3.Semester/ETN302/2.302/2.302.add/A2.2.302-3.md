# Solucion.

---

>- Para el periodo: $$\quad T=2$$

>- Para la 1ra seccion de la señal $$A\sin(\omega ·(x-x_0))$$
>$$\omega = \dfrac{2\pi}{
{\color{Orange}\cancelto{{\color{Orange} 2 }}{{\color{Gray} T }}}}
\Rightarrow\quad\omega = \pi$$

>La onda será:$$\quad f_{1(t)}=1\sin(t·\pi)$$

>- Para la 2da seccion de la señal (recta).
>$$(y-0)={\color{orange} -\dfrac{1/2}{1} }·(x-1)$$
>
>$$f_{2(t)}=\dfrac{\mbox{-}\,1}{2}·(t-1)$$

>- Para el valor medio.
>$$V_m=\dfrac{1}{2}·\left[\,
\int^{1}_{0}\sin(\pi·t)dt+
\int^{2}_{1}\dfrac{\mbox{-}\,1}{2}(t-1)dt
\,\right]$$
>
>$$V_m=\dfrac{1}{2}·\left[\,
\dfrac{\mbox{-}\,\cos(\pi·t)}{\pi}\Bigg |^{1}_0
-\dfrac{1}{2}·\left( \dfrac{t^2}{2}-t
\right)\Bigg |^{2}_{1}
\,\right]$$
>
>$$V_m=\dfrac{1}{2}·\left[\,
\dfrac{\mbox{-}\,1}{\pi}·(
{\color{Orange}\cancelto{{\color{Orange} -1 }}{{\color{Gray} \cos(\pi) }}}
-{\color{Orange}\cancelto{{\color{Orange} 1 }}{{\color{Gray} \cos(0)}}})
-\dfrac{1}{2}·\left(
{\color{orange}\cancel{{\color{Gray}\dfrac{4}{2}}}}
-{\color{orange}\cancel{{\color{Gray}2}}}
-\dfrac{1}{2}+1
\right)\,\right]$$
>
>$$V_m=\dfrac{1}{2}·\left[
\dfrac{\mbox{-}\,1}{\pi}·(-2)
-\dfrac{1}{2}\left(\dfrac{1}{2}\right)
\right]
\Rightarrow\quad 
V_m=\dfrac{1}{2}\left[
\dfrac{2}{\pi}-\dfrac{1}{4}
\right]$$
>
>$$V_m=\dfrac{1}{\pi}-\dfrac{1}{8}$$

>- Para el valor eficaz.
>$$V_\varepsilon =
\sqrt{\dfrac{1}{2}·
\left[
\int^{1}_{0}\sin^2(\pi t)dt+
\int^{2}_{1}\left(\dfrac{\mbox{-}\,1}{2}·(t-1)
\right)^{2}dt
\right]}$$

>Sea la 1ra integral.
>$$I_1=\int^{1}_{0}\dfrac{1}{2}·(1-\cos(2·\pi t))dt = 
\dfrac{1}{2}·\left[ t-\dfrac{\sin(2\pi t)}{2\pi} \right]\Bigg |^{1}_{0}$$
>
>$$I_1=\dfrac{1}{2}·\left[ 1-0-\dfrac{1}{2\pi}·(
{\color{Orange}\cancelto{{\color{Orange} 0 }}{{\color{Gray} \sin(2\pi) }}}
-0) \right]\Rightarrow\quad
I_1=\dfrac{1}{2}$$

>Sea la 2da integral.
>$$I_2=\int^{2}_{1}\dfrac{1}{4}·(1-2t+t^2)dt=
\dfrac{1}{4}\left( 
t-t^2+\dfrac{t^3}{3}
\right)\Bigg |^{2}_{1}$$
>
>$$I_2=\dfrac{1}{4}·\left[
(2-1)-(4-1)+\dfrac{1}{3}·(8-1)
\right]=
\dfrac{1}{4}(1-3+\dfrac{7}{3})$$
>
>$$I_2=\dfrac{1}{4}·\left(
\dfrac{1}{3}\right)\Rightarrow\quad I_2=\dfrac{1}{12}$$
>
>En la ecuacion.
>$$V_\varepsilon = \sqrt{\dfrac{1}{2}·\left(  
\dfrac{1}{2}+\dfrac{1}{12}
\right)}=
\sqrt{\dfrac{1}{2}\times\dfrac{7}{12}}$$
>
>$$V_\varepsilon = \sqrt{\dfrac{7}{24}}$$

>- Finalmente.
>$$f.f.=\dfrac{\sqrt{7/24}}{1/\pi-1/8}$$
>
>$$f.f.=2.784$$
