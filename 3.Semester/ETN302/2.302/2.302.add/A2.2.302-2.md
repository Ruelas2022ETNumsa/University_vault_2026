# Solucion.

---

>- Para el periodo: $T=2$

>- Para le valor medio.
>$$V_m=\dfrac{1}{2}·\int^{1}_{0}4\,dt+
\int^{2}_{1}0\,dt\Rightarrow\quad 
V_m=\dfrac{1}{2}·(4t)\Bigg |^{1}_{0}$$
>
>$$V_m=\dfrac{1}{2}·(4·1)\Rightarrow \quad V_m=2$$

>- Para el valor eficaz.
>$$V_\varepsilon =\sqrt{\dfrac{1}{2}
·\left[ \int^{1}_{0} 4^2\right]\,dt}
\Rightarrow\quad V_\varepsilon = \sqrt{8}$$
>
>$$V_\varepsilon = 2·\sqrt{2}$$

>- Finalmente para el Factor de forma.
>$$f.f.=\dfrac{2\sqrt{2}}{2}\Rightarrow\quad f.f.=1.414$$
