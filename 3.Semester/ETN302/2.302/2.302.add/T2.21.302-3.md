# $\delta_{(t)}$

---

$$\quad A · \delta_{(t-x)}=
\begin{cases}
A & \mbox{; } t= x \\
0 & \mbox{; } t \neq x
\end{cases}$$

```ad-Nota_2
title: Definición
collapse: closed

Intuitivamente se puede imaginar la función $\delta_{(t)}$( Delta de Dirac ) como una función que tiene un valor infinito en $t=0$ ; tiene un valor nulo en cualquier otro punto, de tal manera que su integral es uno.

![[TD2.21.302-4.svg]]

---

$$\qquad F_p=
\begin{cases}
\frac{1}{a} & \mbox{; } a\geq t\geq 0 \\\\
0 & \mbox{; para todo t}
\end{cases}
\qquad\qquad\mbox{Donde :}\quad\mbox{Área = } a · \frac{1}{a} \rightarrow \mbox{Área = } 1$$

![[TD2.21.302-3.svg]]

$$\qquad\lim_{a \to 0}F_p= \delta_{(t)}\qquad \longrightarrow\qquad \delta_{(t)} =
\begin{cases}
1 & \mbox{; } t= 0 \\
0 & \mbox{; }\mbox{para toda t}
\end{cases}$$
```
