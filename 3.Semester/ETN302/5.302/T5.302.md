# TEMA V : Definiciones en topologias de redes

---

## Teoría
### Introducción.
El termino topologia se refiere a la forma de la res que no se altera cuando esta es estira, se cruza o se dobla.

Graficamente el diagrama topologico de una red es es escencia graficar el squeleo de una res donde cada elemente se sustituye por una linea y cada union de elementos se sustituye por un punto.


### Definiciones.
- Red eléctrica.- Es la interconexion de componentes electronicos o eléctricos.

- Res pasiva.- Es aquella red que no genera energia eléctrica, es decir que la red no tiene fuentes, y si las tiene estas se reducen a cero.
	1. De tensión a cero .- Si una tensión se reduce a cero, es equivalente a un cable ideal (corto circuito).
	3. De corriente  cero.- Si una intensidad de corriente se anula se equivalente es una alta impedancia (circuito abierto).

- Nodo.- Es la union de dos o mas elementos.

- Rama.- Es la trayectoria de elementos en serie que puede contener uno o mas elementos.

- Malla.- Es la trayectoria cerrada de la interconexion de los elementos.

- Red plana.- Es una red que puede ser representada graficamente en el plano sin que se cruzen sus conexiones.

- Red no plana.- Tiene conexiones que se cruzan.

- Red totalmente conectada.- Esta totalmente conectada cuando todos sus elementos estan conectados.

- Red parcialemente conectada.- Tiene nodos sueltos.

- Número de elementos.- Cantidad de elementos presentes en Red.
Para saber cuantos elementos estan en la red se utiliza la ecuacion:
>$$(N-1)+M=\mbox{Número de elementos}$$

Donde :
$$N=\mbox{Número de nodos}$$
$$M=\mbox{Número de mallas}$$
