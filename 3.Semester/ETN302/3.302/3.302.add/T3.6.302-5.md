>- Simplificando las resistencias y dibujando las corrientes necesarias.
>![[TE3.6.302-5.png\|350]]

>- Para la corriente $I_{2}$.
>$$I=\dfrac{2{\color{orange}\bcancel {{\color{gray}R}}}}{5{\color{orange}\bcancel {{\color{gray}R}}}}·I_{2}$$
>$$\Rightarrow\quad I_{2}=\dfrac{5}{2}·I\qquad\dots(1)$$

>- Sea la resistencia equivalente.
>$$R_{\mbox{x}}=2R+{\color{orange}\cancelto{{\color{orange}6R/5}}{{\color{gray}\dfrac{2R·3R}{2R+3R}}}}=\dfrac{16R}{5}$$
>- Para la corriente $I_{1}$.
>$$I_{2}=\dfrac{2R}{
{\color{orange}\cancelto{{\color{orange}26R/5}}{{\color{gray}2R+\frac{16R}{5}}}}}·I_{1}$$
>$$\looparrowright\quad I_{1}=\dfrac{26}{10}·I_{2}\qquad\dots(2)$$

>- Reemplazando la ec. $(1)$ en $(2)$.
>$$I_{1}=\dfrac{{\color{orange}\cancelto{{\color{orange}13}}{{\color{gray}26}}}}{{\color{orange}\cancelto{{\color{orange}2}}{{\color{gray}10}}}}·\left(\dfrac{{\color{orange}\cancelto{{\color{orange}1}}{{\color{gray}5}}}}{{\color{orange}\cancelto{{\color{orange}1}}{{\color{gray}2}}}}·I\right)$$
>$$\Rightarrow\quad I_{1}=\dfrac{13}{2}·I\qquad\dots(3)$$


>- Finalmente por L.T.K.
>$$V=2RI_{1}+2RI_{2}+3RI\qquad\dots(4)$$

>- Reemplazando las ec. $(2)$ y $(3)$ en $(4)$.
>$$V={\color{orange}\bcancel {{\color{gray}2}}}R·\left(\dfrac{13}{{\color{orange}\bcancel {{\color{gray}2}}}}·I\right)
+{\color{orange}\bcancel {{\color{gray}2}}}R·\left(\dfrac{5}{{\color{orange}\cancelto{{\color{orange}1}}{{\color{gray}2}}}}·I\right)+3RI$$
>$$\looparrowright\quad V=RI·(13+5+3)=21·{\color{orange}\cancelto{{\color{orange}5}}{{\color{gray}R}}}{\color{orange}\cancelto{{\color{orange}0.2}}{{\color{gray}I}}}$$
>$$\Rightarrow\quad V=21\,[\,V\,]$$
