## 5. Muestreo de la DTFT y cálculo de la DFT con zero-padding

```matlab
% ETN1015 — Discrete Fourier Transform / Cap. 2 Palani · Cap. 5 Proakis
% Ejercicio: Muestreo de la DTFT y cálculo de la DFT con zero-padding (N = 5, 10, 50)
% Fuente: Proakis & Manolakis — Cap. 7 / Ingle & Proakis — Cap. 5
clear; clc; close all;

% [bloque 1 — Definición de señales y parámetros]
% Se definen las primeras 5 muestras (n = 0 a 4) de las señales analizadas
xa = ones(1, 5);          % Señal a: Pulso rectangular discreto 
xb = (0.5).^(0:4);        % Señal b: Exponencial causal truncada [1 0.5 0.25 0.125 0.0625]

N_vals = [5, 10, 50]; % ver corrección en admonition
w_dense = linspace(0, 2*pi, 1000); % Frecuencia densa para la DTFT de referencia continua

% [bloque 2 — Cálculo de las DTFTs continuas de referencia]
% Señal a: Se calcula de forma cerrada (sinc discreto). Se aplica L'Hôpital
% en w = 0 y w = 2*pi para evitar divisiones de tipo 0/0.
Xa_dtft = exp(-j * 2 * w_dense) .* sin(2.5 * w_dense) ./ sin(0.5 * w_dense);
Xa_dtft(abs(sin(0.5 * w_dense)) < 1e-10) = 5; 

% Señal b: Se evalúa directamente la definición de la sumatoria para 5 puntos.
Xb_dtft = zeros(size(w_dense));
for n = 0:4
    Xb_dtft = Xb_dtft + xb(n+1) * exp(-j * w_dense * n);
end

% [bloque 3 — Generación de gráficos de magnitud y fase para la Señal a]
% Figura 1: Magnitud de la Señal a (Superposición con DTFT)
figure(1);
for i = 1:length(N_vals)
    N = N_vals(i);
    X_dft = fft(xa, N);           % FFT de N puntos con zero-padding automático
    w_dft = (0:N-1) * 2 * pi / N; % Vector de frecuencias de muestreo discreto [0, 2*pi]
    
    subplot(3, 1, i);
    plot(w_dense/pi, abs(Xa_dtft), 'r--', 'LineWidth', 1.2); hold on;
    stem(w_dft/pi, abs(X_dft), 'filled', 'b', 'LineWidth', 1.2);
    xlabel('Frecuencia normalizada (\omega / \pi)');
    ylabel('Magnitud');
    title(['Señal a - Magnitud (N = ', num2str(N), ')']);
    xlim([0, 2]); % ver corrección en admonition
    grid on;
    if i == 1
        legend('DTFT referencia', 'DFT muestras');
    end
end

% Figura 2: Fase de la Señal a (Superposición con DTFT)
figure(2);
for i = 1:length(N_vals)
    N = N_vals(i);
    X_dft = fft(xa, N);
    % Limpieza de ruido numérico en fase para muestras con amplitud nula
    X_dft_clean = X_dft;
    X_dft_clean(abs(X_dft_clean) < 1e-10) = 0;
    w_dft = (0:N-1) * 2 * pi / N;
    
    subplot(3, 1, i);
    plot(w_dense/pi, angle(Xa_dtft), 'r--', 'LineWidth', 1.2); hold on;
    stem(w_dft/pi, angle(X_dft_clean), 'filled', 'b', 'LineWidth', 1.2);
    xlabel('Frecuencia normalizada (\omega / \pi)');
    ylabel('Fase (rad)');
    title(['Señal a - Fase (N = ', num2str(N), ')']);
    xlim([0, 2]); % ver corrección en admonition
    ylim([-pi-0.5, pi+0.5]);
    grid on;
end

% [bloque 4 — Generación de gráficos de magnitud y fase para la Señal b]
% Figura 3: Magnitud de la Señal b (Superposición con DTFT)
figure(3);
for i = 1:length(N_vals)
    N = N_vals(i);
    X_dft = fft(xb, N);
    w_dft = (0:N-1) * 2 * pi / N;
    
    subplot(3, 1, i);
    plot(w_dense/pi, abs(Xb_dtft), 'r--', 'LineWidth', 1.2); hold on;
    stem(w_dft/pi, abs(X_dft), 'filled', 'b', 'LineWidth', 1.2);
    xlabel('Frecuencia normalizada (\omega / \pi)');
    ylabel('Magnitud');
    title(['Señal b - Magnitud (N = ', num2str(N), ')']);
    xlim([0, 2]); % ver corrección en admonition
    grid on;
    if i == 1
        legend('DTFT referencia', 'DFT muestras');
    end
end

% Figura 4: Fase de la Señal b (Superposición con DTFT)
figure(4);
for i = 1:length(N_vals)
    N = N_vals(i);
    X_dft = fft(xb, N);
    X_dft_clean = X_dft;
    X_dft_clean(abs(X_dft_clean) < 1e-10) = 0;
    w_dft = (0:N-1) * 2 * pi / N;
    
    subplot(3, 1, i);
    plot(w_dense/pi, angle(Xb_dtft), 'r--', 'LineWidth', 1.2); hold on;
    stem(w_dft/pi, angle(X_dft_clean), 'filled', 'b', 'LineWidth', 1.2);
    xlabel('Frecuencia normalizada (\omega / \pi)');
    ylabel('Fase (rad)');
    title(['Señal b - Fase (N = ', num2str(N), ')']);
    xlim([0, 2]); % ver corrección en admonition
    ylim([-pi-0.5, pi+0.5]);
    grid on;
end
```

2. `xlim()` sin argumentos en las 4 figuras causaría error — valor correcto: `xlim([0, 2])` para mostrar el rango normalizado $\omega/\pi \in [0, 2]$. El archivo `dft_comparacion.m` en el vault tiene ambas correcciones aplicadas.

**Qué hace el código:**
1. **Define las muestras** temporales finitas correspondientes a la Señal a (pulso rectangular uniforme) y a la Señal b (exponencial causal truncada en 5 muestras).
2. **Establece la DTFT de referencia** evaluando las expresiones matemáticas continuas sobre una malla de alta densidad para representar fielmente las transformadas del ejercicio previo.
3. **Aplica límites en frecuencia** mediante reglas condicionales en los puntos de discontinuidad para evitar divisiones de tipo cero sobre cero en el caso de la función sinc.
4. **Calcula la DFT usando zero-padding** de manera directa mediante la función integrada fft() de MATLAB para longitudes de 5, 10 y 50 muestras.
5. **Realiza una limpieza de fase** forzando a cero el valor de las muestras discretas cuya magnitud cae por debajo del nivel de precisión del software, garantizando gráficos de fase libres de ruido numérico en los cruces por cero.
6. **Grafica los resultados superpuestos** en subplots alineados para cada longitud de muestras $N$, mostrando la DTFT continua de referencia (línea punteada roja) y los coeficientes discretos obtenidos mediante DFT (tallos azules con stem), escalando correctamente los ejes de frecuencia de 0 a 2*pi.
