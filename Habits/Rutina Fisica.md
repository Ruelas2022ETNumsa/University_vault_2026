# 🏋️ Rutina Física

## 📋 Referencia de ejercicios

**8 kilos por mancuerna, 10 series de 15 repeticiones y 3 min de descanso entre repeticiones**

| ID  | Ejercicio             | Músculo principal   |
| --- | --------------------- | ------------------- |
| CSu | Curl Supino           | Bíceps              |
| CMa | Curl de Martillo      | Bíceps + Braquial   |
| Tri | Extensión de Tríceps  | Tríceps             |
| PBa | Press de Banca        | Pecho + Tríceps     |
| PMi | Press Militar         | Hombros + Tríceps   |
| ELa | Elevaciones Laterales | Hombros (deltoides) |
| Dom | Dominadas             | Espalda + Bíceps    |
| Abd | Abdominales           | Core                |
| Cam | Caminata Facultad     | Cardio              |
