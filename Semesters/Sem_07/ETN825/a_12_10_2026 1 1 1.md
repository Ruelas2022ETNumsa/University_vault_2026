
| Identificador | Sección | Tamaño       | Rol                                                                                               |
| ------------- | ------- | ------------ | ------------------------------------------------------------------------------------------------- |
| `DR`          | MEMORY  | `(18)`       | Registro de datos que almacena la palabra recibida desde `IOBUS` o leída desde `BUFFER`           |
| `CR`          | MEMORY  | `(8)`        | Registro de carácter que almacena el código ASCII a enviar a la impresora                         |
| `BUFFER`      | MEMORY  | `(1024, 18)` | Memoria RAM interna de 1024 palabras de 18 bits para almacenar el bloque de datos                 |
| `cnt`         | MEMORY  | `(10)`       | Contador y puntero de dirección de 10 bits ($2^{10} = 1024$) para indexar `BUFFER`                |
| `limit`       | MEMORY  | `(10)`       | Registro de 10 bits que guarda la dirección siguiente a la última palabra no vacía recibida       |
| `empty`       | MEMORY  | `(3)`        | Contador de 3 bits para registrar hasta 4 palabras vacías consecutivas                            |
| `busy`        | MEMORY  | `escalar`    | Flip-flop de estado que indica si la interfaz está procesando la recepción o impresión del bloque |
| `first`       | MEMORY  | `escalar`    | Flip-flop de control que selecciona el primer ($1$) o segundo ($0$) carácter ASCII en `DR`        |
| `has_data`    | MEMORY  | `escalar`    | Flip-flop de estado que indica si se recibió al menos una palabra con texto útil no vacío         |
| `end_print`   | MEMORY  | `escalar`    | Flip-flop de estado que indica la llegada a la dirección límite de impresión                      |
| `CHAR`        | OUTPUTS | `(8)`        | Bus de salida combinacional conectado a `CR` hacia la impresora                                   |
| `print`       | OUTPUTS | `escalar`    | Señal de salida que activa la impresión de un carácter en la impresora                            |
| `feed`        | OUTPUTS | `escalar`    | Señal de salida que activa el avance de papel o retorno de carro                                  |
| `wait`        | INPUTS  | `escalar`    | Señal de entrada desde la impresora que indica que la mecánica está ocupada                       |
| `csrdy`       | INPUTS  | `escalar`    | Señal de entrada que indica la presencia de un comando válido en `CSBUS`                          |
| `IOBUS`       | COMBUS  | `(18)`       | Bus de datos bidireccional del sistema de 18 bits                                                 |
| `CSBUS`       | COMBUS  | `(12)`       | Bus de control y selección de dispositivo de 12 bits                                              |
| `ready`       | COMBUS  | `escalar`    | Línea de control que indica disponibilidad para recibir/enviar datos                              |
| `datavalid`   | COMBUS  | `escalar`    | Línea de control que valida la presencia de un dato en el bus                                     |
| `accept`      | COMBUS  | `escalar`    | Línea de control de handshake que confirma la recepción del dato/comando                          |

$\text{MEMORY: } DR(18);\ CR(8);\ BUFFER(1024, 18);\ cnt(10);\ limit(10);\ empty(3);\ busy;\ first;\ has\_data;\ end\_print$

| Paso | Estado resultante |
|-|-|
| `1:` | Espera activa de selección. Permanece en `1` mientras no se direccione la impresora (`010`) con $csrdy = 1$. |
| `2:` | Confirma el comando con $accept = 1$. Bifurca a `3` si es consulta de estatus ($CSBUS_{3} = 1$) o a `1` y `1A` si es orden de salida de datos ($CSBUS_{3} = 0$). |
| `3:` | Espera activa de $ready$ para responder el estatus. |
| `4:` | Entrega $busy$ en $CSBUS_{0}$ con $datavalid = 1$. Vuelve a `1` al recibir $accept$. |
| `1A:` | Inicializa la carga: $cnt$, $empty$ y $limit$ en cero, $has\_data = 0$ y $busy = 1$. |
| `2A:` | Indica disponibilidad con $ready = 1$ y espera mientras $datavalid = 0$. |
| `3A:` | Captura la palabra de $IOBUS$ en $DR$, la guarda en $BUFFER[cnt]$ y emite $accept = 1$. |
| `4A:` | Mantiene $accept = 1$ y espera a que $datavalid$ baje a 0 antes de continuar. |
| `5A:` | Clasifica la palabra: va a `6A` si tiene algún carácter no nulo, o a `7A` si sus dos caracteres son nulos (`00`). |
| `6A:` | Registra texto útil: $has\_data = 1$, $limit$ pasa a la dirección siguiente $INC(cnt)$ y $empty$ se reinicia a cero. Salta a `8A`. |
| `7A:` | Cuenta una palabra vacía más con $empty \leftarrow INC(empty)$. Salta a `8A`. |
| `8A:` | Incrementa $cnt$. Pasa a imprimir (`1B`) si hay 4 vacías consecutivas ($empty_{0} = 1$) o si el buffer se llenó ($\bigwedge / cnt = 1$ con el valor previo); si no, recibe la siguiente palabra en `2A`. |
| `1B:` | Reinicia $cnt$ a cero. Sin texto útil ($has\_data = 0$) salta a `11B` sin imprimir; con texto va a `2B`. |
| `2B:` | Lee $BUFFER[cnt]$ en $DR$ e inicia por el primer carácter ($first = 1$). |
| `3B:` | Desempaqueta el carácter: $DR_{10:17}$ si $first = 1$, $DR_{1:8}$ si $first = 0$. |
| `4B:` | Activa $feed$ si $CR$ es retorno de carro, o $print$ si es un carácter imprimible. |
| `5B:` | Paso nulo de sincronización para que la impresora levante $wait$. |
| `6B:` | Espera mientras la impresora esté ocupada ($wait = 1$). |
| `7B:` | Si acaba de imprimir el primer carácter ($first = 1$) vuelve a `3B` por el segundo; si fue el segundo, avanza a `8B`. |
| `8B:` | Apunta a la siguiente palabra del buffer con $cnt \leftarrow INC(cnt)$. |
| `9B:` | Compara el nuevo $cnt$ con $limit$ bit a bit (XOR negado y reducción AND) y guarda el resultado en $end\_print$. |
| `10B:` | Si $end\_print = 1$ termina en `11B`; si no, vuelve a `2B` por la siguiente palabra. |
| `11B:` | Libera la interfaz con $busy = 0$, tras imprimir el bloque o directamente desde `1B` si no hubo texto útil. |
| `12B:` | Fin de la secuencia del bloque. |
