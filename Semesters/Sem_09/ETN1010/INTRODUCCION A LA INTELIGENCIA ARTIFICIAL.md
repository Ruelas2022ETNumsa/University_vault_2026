„Machine learning‟ comenzo a florecer en los 1990s.
„Machines learning‟ esta relacionada a las estadísticas matemáticas.
Esta trabaja con grandes y complejas cantidades de datos.
Machine learning descubre reglas para ejecutar una tarea de
procesamiento de datos.

---

Para realizar un Machine Learning, necesitamos tres cosas:

1. Datos entrada.- Por ejemplo, si la tarea es de reconocimiento de
   voz, estos datos de entrada podrían ser archivos de sonido de
   personas hablando.

2. Ejemplos de las salidas esperadas.- En una tarea de reconocimiento
   de voz, estas podrían ser transcripciones de archivos de sonido
   generadas por humanos.

3. Una forma de medir si el algoritmo esta realizando el trabajo
   deseado. Es necesario determinar la distancia entre la salida actual
   del algoritmo con la salida esperada. Esta medida es usada como
   una señal de retroalimentación para ajustar de manera que el
   algoritmo trabaje. Este ajuste es lo que se llama aprendizaje.

---

Un modelo de Machine Learning transforma sus datos de entrada a
salidas que tengan significado.

El problema central en Machine Learning and Deep Learning es
transformar los datos de manera que tengan significado. En otras
palabras, para que aprenda representaciones utiles de los datos de
entrada, estas deben llevarnos cerca a los datos salida esperados.

Las representaciones son diferentes formas de ver los datos, por

## DEEP LEARNING

Deep learning es un subcampo especifico de Machine learning.

Este nombre viene de idea de las capas sucesivas de representación
que puede tener un modelo.

La cantidad de capas contribuyen al modelo de los datos de entrada,
tambien se llama „la profundidad del modelo‟ (10 a 100)

En deep learning, las representaciones de las capas son aprendidos
via modelos „Redes Neuronales‟.
