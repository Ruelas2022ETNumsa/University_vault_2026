# Ejercicio 2 — Convolución lineal de secuencias discretas

Determinar la convolución lineal $y(n) = x(n) * h(n)$, donde $x(n)$ es la entrada y $h(n)$ la respuesta al impulso. Graficar la salida en todos los instantes donde $y(n) \neq 0$.

$$
x(n)=[1\quad 1\quad 1\quad 1], \quad n = 0,1,2,3
$$

$$
h(n)=[1\quad 2\quad 3], \quad n = 0,1,2
$$

---

## Resolución analítica

### Soporte de la salida

$$
L_y = N_x + N_h - 1 = 4 + 3 - 1 = 6 \quad \Rightarrow \quad n \in [0,\ 5]
$$

### Suma de convolución

Como $x(k) = 1$ para todo $k \in \{0,1,2,3\}$, la suma se reduce a:

$$
y(n) = \sum_{k=0}^{3} h(n-k)
$$

Desarrollo término a término:

| $n$ | Productos $x(k)\,h(n-k)$ | $y(n)$ |
|:---:|:---|:---:|
| 0 | $h(0) = 1$ | **1** |
| 1 | $h(1)+h(0) = 2+1$ | **3** |
| 2 | $h(2)+h(1)+h(0) = 3+2+1$ | **6** |
| 3 | $h(2)+h(1)+h(0) = 0+3+2+1$ | **6** |
| 4 | $h(2)+h(1) = 3+2$ | **5** |
| 5 | $h(2) = 3$ | **3** |

$$
\boxed{y(n) = \{\underline{1},\ 3,\ 6,\ 6,\ 5,\ 3\}, \quad 0 \le n \le 5}
$$

### Tabla de productos desplazados

| $k$ | 0 | 1 | 2 | 3 | 4 | 5 | $y(n)$ |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| $x(k)$ | **1** | **1** | **1** | **1** | 0 | 0 | |
| $h(0-k)$ | 1 | 0 | 0 | 0 | 0 | 0 | **1** |
| $h(1-k)$ | 2 | 1 | 0 | 0 | 0 | 0 | **3** |
| $h(2-k)$ | 3 | 2 | 1 | 0 | 0 | 0 | **6** |
| $h(3-k)$ | 0 | 3 | 2 | 1 | 0 | 0 | **6** |
| $h(4-k)$ | 0 | 0 | 3 | 2 | 1 | 0 | **5** |
| $h(5-k)$ | 0 | 0 | 0 | 3 | 2 | 1 | **3** |

## Código MATLAB

```matlab
% ETN1015 — Ejercicio 2: Convolución lineal discreta
% Ref: Palani Cap. 1 · Oppenheim EN (6to11) Cap. 6 · Ingle & Proakis Cap. 2
clear; clc; close all;

x = [1, 1, 1, 1];  nx = 0:3;
h = [1, 2, 3];     nh = 0:2;

y = conv(x, h);
ny = (nx(1)+nh(1)) : (nx(end)+nh(end));

figure(1);
stem(ny, y, 'filled', 'LineWidth', 1.5, 'Color', [0 0.4470 0.7410]);
xlabel('n'); ylabel('y(n)');
title('y(n) = x(n) * h(n)');
xlim([ny(1)-1, ny(end)+1]); ylim([0, max(y)+1]);
grid on;
```
