## Organización y Arquitectura del Computador SIC (24 pasos)


1. Definición formal
El computador SIC (Small Instructional Computer) es un procesador de palabra de 18 bits con direccionamiento de una sola dirección, espacio de direccionamiento de 8192 palabras de memoria y dos registros de índice, diseñado como un modelo de referencia para el diseño de hardware mediante lenguaje de transferencia de registros (AHPL).

2. Idea clave
La secuencia de control de 24 pasos de SIC resuelve de forma síncrona y cableada las fases de búsqueda (fetch), direccionamiento (directo, indirecto e indexado) y ejecución para las siete instrucciones direccionadas a memoria (ISZ, LAC, AND, TAD, JMS, DAC, JMP) utilizando una estructura compartida de tres buses: ABUS, BBUS y OBUS.

Secuencia de Control de 24 Pasos en AHPL:

```ahpl
MODULE: SIC
MEMORY: AC; MD; PC; IR; IA; IB; MA; lf; M
INPUTS: start
BUSES: ABUS; BBUS; OBUS

CONTROL SEQUENCE:
1.   -> (SL(SYN(start))) / (1)                             // Espera síncrona del bit de inicio start
2.   MA <- PC                                              // Carga dirección de la instrucción
3.   MD <- BUSFN(M; DCD(MA))                               // Lectura de memoria
4.   IR <- MD                                              // Carga de instrucción en IR
5.   -> (IR & IR & IR) / (25)                     // Exclusión de instrucciones operativas (111)
6.   -> (IR) / (10)                                     // Bifurcación si hay indexación

// Direccionamiento directo o indirecto (sin indexación)
7.   MA <- IR[5:17]
     -> (IR) / (9)                                      // Si es indirecto, va a buscar el puntero
8.   -> (13)                                               // Direccionamiento directo completado

// Resolución de dirección indirecta (compartido)
9.   MD <- BUSFN(M; DCD(MA))                               // Lee la dirección indirecta de memoria
     MA <- MD[5:17]                                        // Carga la dirección final en MA
     -> (13)                                               // Va a la fase de ejecución

// Direccionamiento indexado
10.  -> (IR) / (11)                                    // Elige registro índice (si 0 -> IA, si 1 -> IB)
10-1. MA <- ADD(IA; IR[5:17])                              // Suma IA a la dirección actual
      -> (12)
11.  MA <- ADD(IB; IR[5:17])                               // Suma IB a la dirección actual
12.  -> (IR) / (9)                                      // Si es indirecto, va a buscar el puntero (Indexado-Indirecto)
     -> (13)                                               // Si es directo indexado, va a ejecución

// Fase de ejecución de instrucciones direccionadas
13.  -> (IR) / (14)                                     // Bifurcación para lectura (IR_0=0) o escritura/salto (IR_0=1)

// Lectura de operando para ISZ, LAC, AND, TAD
13-1. MD <- BUSFN(M; DCD(MA))                              // Lee el operando de memoria
13-2. -> (~IR & ~IR) / (22)                         // Si es ISZ (000), bifurca al paso 22
13-3. -> (17)                                              // LAC, AND o TAD van a decodificación de 3 vías

// Decodificación de 3 vías para LAC, AND, TAD
17.  NO DELAY
     (~IR & IR), (IR & ~IR), (IR & IR) / (18, 19, 20)

18.  BBUS = MD; OBUS = 0, BBUS; AC <- OBUS[1:18]           // LAC: AC <- MD
     -> (24)
19.  ABUS = AC; BBUS = MD; OBUS = 0, (ABUS & BBUS); AC <- OBUS[1:18] // AND: AC <- AC ^ MD
     -> (24)
20.  ABUS = AC; BBUS = MD; OBUS = ADD(ABUS; BBUS); lf, AC <- OBUS    // TAD: lf, AC <- AC + MD
     -> (24)

// Instrucciones de Escritura/Salto (JMP, DAC, JMS)
14.  -> (IR) / (15)                                     // Bifurca si es JMP (110) o DAC/JMS
15.  PC <- MA                                              // JMP: PC <- MA
     -> (1)
16.  -> (IR) / (16-DAC)                                 // Bifurca a DAC (101) o JMS (100)

16-DAC. M * DCD(MA) <- AC                                  // DAC: Guarda AC en memoria
        -> (24)

16-JMS. M * DCD(MA) <- PC                                  // JMS: Guarda PC de retorno en MA
16-JMS-2. PC <- INC(MA)                                    // PC <- MA + 1 (inicio de la subrutina)
          -> (1)

// Instrucción ISZ (000)
22.  MD <- INC(MD)                                         // Incrementa el operando
23.  M * DCD(MA) <- MD                                     // Guarda el nuevo valor en memoria
     -> (\/MD) / (24)                                      // Si el valor no es cero, va a 24 para finalizar
23-1. PC <- INC(PC)                                        // Si es cero, salta una instrucción (PC <- PC + 1)

// Fin de ciclo de instrucción común (Incremento de PC)
24.  PC <- INC(PC)                                         // Incrementa PC para la siguiente instrucción
     -> (1)
```
